# Ezlang

Ezlang is a simple and beginner-friendly programming language inspired by Python.

## Features
- Easy-to-read syntax
- Supports functions, loops, and conditionals
- Built-in error handling

## How to Run
1. Install Python (if not already installed)
2. Run an Ezlang script using:
   ```
   python ezlang.py example.ez
   ```

## Example
Create a file `hello_world.ez`:
```ez
func greet():
    show("Hello, Ezlang!")

greet()
```
Run it:
```
python ezlang.py hello_world.ez
```
```
Hello, Ezlang!
```
